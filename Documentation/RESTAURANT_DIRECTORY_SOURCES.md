# Synthetic restaurant seed data

The API prototype seeds ten fictional restaurant names for each of its 25 supported Nordic municipalities. Cuisine labels and city assignments provide varied examples for browsing; names, venue details, ratings, reviews, and people are demo data and do not describe real businesses or customers.

The directory has no street addresses, website links, photos, or endorsements. It is generated as local sample data so the prototype can be explored without a restaurant service or external business API.
