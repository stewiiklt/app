# Restaurant directory seed sources

The curated directory was researched on 24 October 2026 from current restaurant, destination, and food-guide listings. It provides starter discovery data; selection does not imply endorsement. Names and broad cuisine labels are included. Addresses are municipality and country only because exact street addresses were not confirmed for every entry. Seeded entries deliberately have no photos, website claims, ratings, review counts, or opening-date claims.

The seed targets the 25 municipality IDs in `SeedData.cs` (five each in Norway, Sweden, Denmark, Finland, and Iceland). These are the source guides consulted for the selections; entries were cross-checked against city guides and current dining lists, and lists may change as businesses open or close.
